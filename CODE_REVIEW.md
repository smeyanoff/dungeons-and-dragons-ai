## 🔴 Важные проблемы (требуют исправления)

### 1. Не отображаются игрок и спутники в порядке ходов боя (FEEDBACK.md #1)

**Проблема:** В сообщении "⚔️ Бой начался! Порядок ходов:" отображаются только враги, но не отображаются игрок и его спутники.

**Файлы:** 
- `internal/game/domain/combat/combat.go:376-402` - `GetInitiativeOrderMessage()`

**Возможные причины:**
1. Неправильная нумерация в `GetInitiativeOrderMessage()` - используется индекс `i` из цикла вместо порядкового номера в порядке инициативы
2. Спутники (NPC companions) могут не добавляться в `Combat.Participants` при создании боя

**Решение:**
- Исправить нумерацию в `GetInitiativeOrderMessage()` - использовать отдельный счетчик вместо индекса массива
- Проверить, что при создании боя все участники (игрок + спутники + враги) добавляются в `Combat.Participants`

**Приоритет:** Высокий ⚠️  
**Статус:** ⚠️ Требует исправления

---

### 2. Враги не выполняют ходы автоматически (FEEDBACK.md #2)

**Проблема:** Когда текущий ход принадлежит врагу, DM не описывает автоматически действие врага и не выполняет его атаку.

**Файлы:**
- `internal/game/application/player_action/handle_action.go` - обработка действий игрока

**Решение:**
- После хода игрока проверять, чей следующий ход
- Если следующий ход врага - автоматически генерировать ответ DM с описанием действия врага и его атаки
- Использовать `PerformCombatAttackTool` для автоматической атаки врагов
- Добавить инструкции для DM: "Если текущий ход принадлежит врагу, ОБЯЗАТЕЛЬНО опиши его действие и используй `perform_combat_attack` для атаки по игроку"

**Приоритет:** Высокий ⚠️  
**Статус:** ⚠️ Требует исправления

## ⚠️ Проблемы безопасности (из PROBLEMS.md)

**Примечание:** Старые проблемы безопасности (#1, #2, #3) решены - см. раздел "Решенные проблемы"

### HIGH severity (требуют исправления)

**1. Integer overflow conversions (CWE-190) - 2 места** ⚠️ **НОВЫЕ ПРОБЛЕМЫ**
- `internal/game/domain/dice/dice.go:139` - uint64 -> int conversion
- `pkg/gigachat/auth.go:153` - int -> uint conversion

**2. Weak random number generator (CWE-338)** ⚠️ **НОВАЯ ПРОБЛЕМА**
- `internal/game/application/character/create_character.go:108` - math/rand вместо crypto/rand

### MEDIUM severity (рекомендуется исправить)

**3. Weak cryptographic primitive (MD5)**
- `internal/game/application/image/generate_image.go:75` - использование MD5 для хэширования

**4. Слабые права доступа к файлам - 2 места**
- `internal/game/application/image/image_storage.go:30` - 0755 вместо 0750
- `internal/game/application/image/image_storage.go:43` - 0644 вместо 0600

**5. Alpine 3.19.9 больше не поддерживается**
- Требуется обновление до Alpine 3.20+ (низкий приоритет, уязвимостей не найдено)

### LOW severity (низкий приоритет)

**6. Необработанные ошибки (CWE-703) - 2 места**
- `pkg/gigachat/client.go:60` - ошибка закрытия Body не обрабатывается
- `internal/game/application/combat/handle_combat.go:96` - ошибка сохранения игнорируется

**Статус:** ⚠️ Требуют исправления (см. PROBLEMS.md для деталей)
