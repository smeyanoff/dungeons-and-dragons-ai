## 🔴 P0 — Блокеры / безопасность

### 1) Prod: Qdrant помечен `unhealthy` из‑за старого/сломленного healthcheck (не из‑за падения Qdrant)
- **Факт:** в уже развернутом проде healthcheck мог остаться старым (`wget: not found`), при этом `/healthz` внутри контейнера отвечает `200 OK`.
- **Риск:** оркестрация/мониторинг считают Qdrant “мертвым” → перезапуски/алерты/ложные деградации.
- **Action items:**
  - Пересоздать контейнеры prod с актуальным `build/docker-compose.prod.yml` (в репо healthcheck уже без `wget/curl`, через `/dev/tcp` + `GET /healthz`).
  - Убедиться, что внешние мониторинги дергают **`/healthz` или `/readyz`**, а не `/health` (404).
- **Трекинг:** `TASKS.md` → **P0.1**
- **Источники:** `docker ps`, `docker inspect dnd-qdrant-prod`.
