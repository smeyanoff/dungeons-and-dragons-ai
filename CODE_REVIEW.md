## ⚠️ Архитектурные проблемы (Backlog)

### 1. Дублирование структур Location и NPC

**Файлы:** 
- `internal/game/domain/location/location.go` ↔ `internal/game/domain/world/location.go`
- `internal/game/domain/npc/npc.go` ↔ `internal/game/domain/world/npc.go`

**Проблема:** Две версии структур в разных пакетах, возможна потеря данных при конвертации

**Решение:** Объединить структуры в единые domain модели

**Статус:** ⚠️ Архитектурная проблема (backlog, низкий приоритет)

## ✅ Решенные проблемы (Январь 2025)

### Критические проблемы боевой системы:
1. ✅ **Неправильный расчет HP/AC/броска в бою** (TASKS.md #64)
   - Решение: Добавлен `Preload("Participants.Character.Stats")` в `CombatRepository.GetActiveBySessionID()` и `GetByID()`
   - Исправлено создание участников боя с HP=0 в DM Analyzer

2. ✅ **DM выдумывает союзников/товарищей в бою** (TASKS.md #65)
   - Решение: Добавлена информация о количестве игроков в сессии в `RAGContextBuilder.BuildContext()`
   - Добавлены инструкции DM о использовании только реальных участников боя

3. ✅ **Валидатор блокирует поднятие предметов из мира** (TASKS.md #66)
   - Решение: Валидация перенесена на DM tools (`validate_item_usage`, `check_stat_requirements`)
   - `ActionValidator` больше не проверяет инвентарь для действия "взять"

### Важные проблемы:
4. ✅ **DM Analyzer - периодические ошибки парсинга JSON** (TASKS.md #4)
   - Решение: Увеличен `max_tokens` с 512 до 1024
   - Улучшен промпт с явными инструкциями о завершении JSON

### Безопасность:
5. ✅ **Integer overflow conversions (CWE-190)** - исправлено (TASKS.md #1)
6. ✅ **Weak random number generator (CWE-338)** - заменено на crypto/rand (TASKS.md #2)
7. ✅ **Alpine 3.18 не поддерживается** - обновлено до Alpine 3.19 (TASKS.md #3)

### Боевая система:
8. ✅ **Боевая система не работала во время боя** - полностью исправлено через tools (TASKS.md #55, #56, #53, #54)
9. ✅ **Поочередные ходы в бою** - реализовано через tools (TASKS.md #52)
10. ✅ **DM запрашивает проверки характеристик** - реализовано через tools (TASKS.md #57)
11. ✅ **Сравнение характеристик для урона** - реализовано через tools (TASKS.md #58)
12. ✅ **Атаки противников** - реализовано через tools (TASKS.md #59)
13. ✅ **Визуализация поля боя** - реализовано через tools (TASKS.md #60)
14. ✅ **Отображение перков и заклинаний** - реализовано через tools (TASKS.md #61)
15. ✅ **Индикатор статуса боя** - реализовано (TASKS.md #63)

### Другие исправления:
16. ✅ **Race conditions в combat системе** - добавлен `sync.RWMutex` (TASKS.md #3)
17. ✅ **DM выдумывает предметы в инвентаре** - проверка `isInventoryQuery()` и автоматическая загрузка инвентаря
18. ✅ **Ошибка парсинга JSON в DM Analyzer** - добавлен fallback механизм (TASKS.md #2)
19. ✅ **Foreign key constraint при удалении сессии** - удаление связанных игроков в транзакции
20. ✅ **GigaChat API - ошибка аутентификации 400** - retry механизм с exponential backoff
21. ✅ **Команда /help и меню команд бота** - реализовано (TASKS.md #62)
