## 🟡 Средние проблемы

### 2. Dockerfile: Незафиксированные версии пакетов в apk

**Файл:** `build/Dockerfile:5, 36`

**Проблема:**
```dockerfile
RUN apk add --no-cache git ca-certificates tzdata
RUN apk --no-cache add ca-certificates tzdata wget
```

**Риск:** Непредсказуемые обновления пакетов могут привести к проблемам совместимости или безопасности.

**Решение:** Зафиксировать версии пакетов:
```dockerfile
RUN apk add --no-cache git=2.43.0-r1 ca-certificates=20240226-r0 tzdata=2024a-r0
RUN apk --no-cache add ca-certificates=20240226-r0 tzdata=2024a-r0 wget=1.21.4-r3
```

**Примечание:** 
- Версии должны периодически обновляться для устранения уязвимостей
- В Alpine Linux фиксация точных версий пакетов не всегда рекомендуется, так как версии могут отличаться на разных архитектурах
- Альтернатива: регулярное сканирование уязвимостей через Trivy и обновление базового образа Alpine
- Текущее решение: используем фиксированную версию Alpine 3.18, которая автоматически получает обновления безопасности через репозиторий

**Статус:** ⚠️ Частично решено (зафиксирована версия Alpine), версии пакетов не зафиксированы (рекомендуется для Alpine)

### 4. Gosec: Integer overflow conversions (CWE-190) - HIGH severity

**Файлы:** 
- `internal/game/domain/dice/dice.go:139` - uint64 -> int conversion
- `pkg/gigachat/auth.go:153` - int -> uint conversion

**Проблема:** Преобразования типов без проверки на переполнение:
```go
// dice.go:139
return int(randomValue % uint64(max))  // uint64 -> int может переполниться

// auth.go:153
backoff := initialBackoff * time.Duration(1<<uint(attempt-1))  // int -> uint может переполниться
```

**Риск:** HIGH - Integer overflow может привести к непредсказуемому поведению, ошибкам выполнения или уязвимостям безопасности.

**Решение:** 
- Добавить проверки диапазонов перед преобразованием
- Использовать безопасные преобразования с проверкой границ
- Для dice: ограничить max значением, чтобы результат помещался в int
- Для auth: ограничить attempt максимальным значением для shift

**Статус:** ⚠️ Требует исправления

### 5. Gosec: Weak random number generator (CWE-338) - HIGH severity

**Файл:** `internal/game/application/character/create_character.go:108`

**Проблема:** Использование `math/rand` вместо `crypto/rand`:
```go
rng := rand.New(rand.NewSource(time.Now().UnixNano()))
```

**Риск:** HIGH - Детерминированный генератор случайных чисел может быть предсказуемым. Для генерации характеристик персонажей это может влиять на игровой баланс.

**Примечание:** Для генерации характеристик персонажей лучше использовать криптографически стойкий генератор для обеспечения случайности.

**Решение:**
```go
// Использовать crypto/rand для криптографически стойкого генератора
import "crypto/rand"
// или использовать rand.Seed(time.Now().UnixNano()) и rand.Intn()
```

**Статус:** ⚠️ Требует исправления

### 6. Gosec: Weak cryptographic primitive (MD5) - MEDIUM severity

**Файлы:**
- `internal/game/application/image/generate_image.go:5, 75` - Использование MD5 для хэширования

**Проблема:** Использование слабого криптографического примитива MD5:
```go
import "crypto/md5"
hash := md5.Sum([]byte(req.UserPrompt))
```

**Риск:** MEDIUM - MD5 считается криптографически небезопасным для целей безопасности. Для генерации имени файла это менее критично, но не рекомендуется.

**Решение:**
```go
import "crypto/sha256"
hash := sha256.Sum256([]byte(req.UserPrompt))
// Или использовать более короткий хэш: hash[:8] для имени файла
```

**Статус:** ⚠️ Требует исправления (низкий приоритет для имени файла)

### 7. Gosec: Слабые права доступа к файлам - MEDIUM severity

**Файл:** `internal/game/application/image/image_storage.go:30, 43`

**Проблема:** Использование слишком открытых прав доступа:
```go
// Строка 30: Директория с правами 0755
os.MkdirAll(basePath, 0755)  // Рекомендуется 0750 или менее

// Строка 43: Файл с правами 0644
os.WriteFile(filePath, imageData, 0644)  // Рекомендуется 0600 или менее
```

**Риск:** MEDIUM - Открытые права доступа могут позволить неавторизованным пользователям читать файлы.

**Решение:**
```go
os.MkdirAll(basePath, 0750)  // Только владелец и группа
os.WriteFile(filePath, imageData, 0600)  // Только владелец
```

**Статус:** ⚠️ Требует исправления (низкий приоритет)

### 9. Gosec: Необработанные ошибки (CWE-703) - LOW severity

**Файлы:**
- `pkg/gigachat/client.go:60` - Ошибка закрытия Body не обрабатывается
- `internal/game/application/combat/handle_combat.go:96` - Ошибка сохранения не обрабатывается

**Проблема:** Игнорирование ошибок может привести к утечкам ресурсов или потере данных:
```go
// client.go:60
resp.Body.Close() // Закрываем предыдущий ответ - ошибка игнорируется

// handle_combat.go:96
uc.combatRepo.Save(ctx, activeCombat) // Ошибка сохранения игнорируется
```

**Риск:** LOW - Игнорирование ошибок может привести к проблемам, но не критично для безопасности.

**Решение:**
- Обрабатывать ошибки явно или логировать их
- Для закрытия Body использовать `defer resp.Body.Close()` или проверять ошибку
- Для сохранения проверять ошибку и обрабатывать соответствующим образом

**Статус:** ⚠️ Требует исправления (низкий приоритет)
