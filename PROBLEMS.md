- **Симптом**: `combat_detected=false` при явных признаках атаки
- **Влияние**: Бой не начинается автоматически

## ⚠️ ВАЖНЫЕ ПРОБЛЕМЫ (P1)

### PostgreSQL: Некорректное завершение работы
- **Статус**: АКТИВНАЯ
- **Симптом**: Automatic recovery при каждом запуске
- **Влияние**: Замедление старта, риск потери данных
- **Приоритет**: P1 - ВЛИЯЕТ НА НАДЕЖНОСТЬ
- **Ответственный**: Команда DevOps/Infrastructure

### Telegram Polling: EOF ошибки
- **Статус**: АКТИВНАЯ
- **Симптом**: `unexpected EOF` при получении обновлений
- **Влияние**: Прерывания в коммуникации с пользователями
- **Приоритет**: P1 - ВЛИЯЕТ НА UX
- **Ответственный**: Команда Backend

### Location Events: Отсутствие в DM prompt
- **Статус**: АКТИВНАЯ
- **Симптом**: Events создаются но не используются в следующем ответе DM
- **Влияние**: Игрок не видит результатов location events
- **Приоритет**: P1 - ОГРАНИЧИВАЕТ ФУНКЦИОНАЛЬНОСТЬ
- **Ответственный**: Команда AI/RAG
