# Активные проблемы разработки (2026-01-23)

## 🚨 КРИТИЧНЫЕ ПРОБЛЕМЫ (P0)

### GigaChat API: Context Deadline Exceeded
- **Статус**: В ПРОЦЕССЕ ИСПРАВЛЕНИЯ
- **Симптом**: `context deadline exceeded` при всех LLM запросах (30s timeout)
- **Влияние**: Невозможно создать кампанию, полный блок игрового процесса
- **Приоритет**: P0 - БЛОКИРУЕТ ВСЕ LLM ФУНКЦИИ
- **Метрики**: 100% failure rate, постоянные retry без backoff
- **Ответственный**: Команда DevOps/Infrastructure + AI/LLM
- **Исправления**: ✅ Выбор правильного HTTP клиента (imageClient для изображений, client для текста) + улучшенный rate limiting (2 RPS, burst=1)

### DM Analyzer: Усеченные JSON ответы
- **Статус**: АКТИВНАЯ
- **Симптом**: JSON обрывается посередине (`"items_received":[`, `"npc_met":n`)
- **Влияние**: Location events не генерируются, бой может не стартовать
- **Приоритет**: P0 - БЛОКИРУЕТ ОСНОВНОЙ ГЕЙМПЛЕЙ
- **Метрики**: `analyzer_json_empty_json count=6`
- **Ответственный**: Команда AI/LLM

### Combat Detection: Неправильное определение боя
- **Статус**: АКТИВНАЯ
- **Симптом**: `combat_detected=false` при явных атаках ("гоблин атакует")
- **Влияние**: Бой не начинается автоматически
- **Приоритет**: P0 - ЛОМАЕТ БОЕВУЮ СИСТЕМУ
- **Ответственный**: Команда AI/LLM

### Блокировка после успешной проверки
- **Статус**: АКТИВНАЯ
- **Симптом**: Даже после успеха (d20=17) система пишет "проверка уже выполнена"
- **Влияние**: Успешные проверки тоже блокируют игру
- **Приоритет**: P0 - ЛОМАЕТ ОСНОВНОЙ ГЕЙМПЛЕЙ
- **Ответственный**: Команда Backend/Game Logic
