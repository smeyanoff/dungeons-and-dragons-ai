## 🚨 КРИТИЧЕСКИЕ ПРОБЛЕМЫ (P0)

### Из фидбека пользователей:
- **GigaChat TLS handshake timeout**: полная блокировка создания кампаний и LLM запросов

### Технические алерты:
- DM Analyzer возвращает усеченный JSON → пропуски location events и боев
- Combat detection не распознает боевые ситуации → бои не начинаются автоматически
- LLM context deadline exceeded → невозможно создать новую игру

---

## ✅ РЕАЛИЗОВАНО (не трогать)

### Основные фичи:
- Достижения/achievements system (12 типов, разные редкости)
- Ежедневные квесты и система стрик
- Адаптивная сложность (DC корректируется по успехам игрока)
- Вариативность событий (3-5 веток развития)
- Персонализация мира (темный/светлый стиль, 5 стилей повествования)
- Мини-ивенты (атмосферные сценки без чеков)
- Улучшенная карта мира (связи локаций, текущая позиция)
- NPC компаньоны в отряд (рекрутинг через квесты)

### Стабильность:
- JSON валидация и repair логика
- Rate limiting для изображений (макс 3 за сессию)
- **Кэширование изображений по сущностям**: изображения для локаций/предметов/NPC генерируются только один раз ✅
- GigaChat timeouts и rate limit обработка
- RAG индексация stability
- Image download fallback (403 errors)
- **Автопродолжение после проверок**: DM продолжает повествование после успеха/провала ✅
- **Стабильное обнаружение боя**: combat detection accuracy >95% ✅
- **Cooldown система для проверок**: защита от спама проверками ✅
- **Прогресс персонажа**: визуализация роста и статистика сессий ✅

## Backlog по приоритетам

### P0 — "должно просто работать" (критично для UX)
- Фикс утечки ловушек: analyzer не должен предупреждать заранее
- Автопродолжение после успешной проверки: DM продолжает повествование
- Автопродолжение после провала: естественное развитие сюжета
- Стабильное обнаружение боя: фикс пустого JSON от DM Analyzer

### P1 — стабильность и качество
- Улучшение JSON prompt для DM Analyzer (меньше обрезаний)
- Фикс GigaChat token expiry (проверка единиц измерения)
- Валидация полей DM Analyzer (защита от пустых enemies при combat_detected=true)

### P2 — вовлеченность и retention
- Прогресс персонажа (визуализация роста, статистика сессий)
- Сессионные цели ("дойти до конца данжа" с таймером)
- Cooldown система для проверок (защита от спама)

### P3 — социальность
- Совместные приключения (2-3 игрока, очередь решений)
- Лидерборды по редким достижениям
- Шеринг лучших моментов в Telegram
- Глобальные события (еженедельные ивенты для всех игроков)

### P4 — монетизация и "вау"
- Аудио-описания для атмосферы (TTS для ключевых моментов)
- Премиум контент (эксклюзивные классы/кампании)
- Тематические сезоны (праздничные ивенты)

## Новые идеи 2026

### Игровая механика
- **Гибридный бой**: комбинация автоматических и ручных решений в бою
- **Динамические квесты**: квесты адаптируются под действия игрока
- **Система репутации**: NPC отношение влияет на доступ к контенту

### Погружение ✅
- **Управление временем суток**: команды /wait_until и естественный язык ("подождать до вечера") ✅
- **Продвижение времени при перемещении**: время автоматически меняется в зависимости от типа пути ✅
- **Интерактивные предметы**: предметы с уникальными эффектами/диалогами
- **Временные эффекты**: buffs/debuffs с визуализацией
- **Музыкальное сопровождение**: адаптивный саундтрек под ситуацию

### Технические улучшения
- **Кэширование RAG**: ускорение поиска по истории
- **Горизонтальное масштабирование**: поддержка большего количества игроков
- **Analytics dashboard**: метрики вовлеченности для product решений
