## Текущий продуктовый фокус (P0): "событие локации → (возможно) проверка → бросок игроком"

### Проблема
- **Промпт‑инструкции не лечат механику**: DM спамит проверками, темп ломается, игрок раздражён.
- **Главный сигнал из feedback**: проверки должны быть редкими и значимыми.

### Цель
- Проверка — решение анализатора/рантайма с guardrails (budget/cooldown/anti-trivial).
- Обязательные reason + stakes, корректный pending → roll → resolve цикл.

### Жёсткие UX‑принципы ✅ (реализовано)
- **Text-only**: взаимодействие сообщениями.
- Игрок не инициирует проверки (только система).
- DM не просит /roll, не показывает "внутреннюю кухню".
- **Analyzer-first проверки**: ✅ анализатор решает "нужна ли проверка" без участия LLM-DM.
- **Guardrails**: ✅ budget/cooldown/anti-trivial + reason/stakes required.

### Мини‑контракт поведения (player-facing)
- Без pending check: `/roll` = просто бросок.
- С pending check: `/roll` резолвит ровно 1 проверку.

## Backlog по приоритетам

### P0 — "должно просто работать"
- **Location events lifecycle**: 0..N событий на локацию, статусы `pending/resolved/expired`.
- **Analyzer-first checks**: анализатор решает "нужна ли проверка" без участия LLM-DM.
- **Text roll UX**: `/roll` / `/roll d20` + парсинг естественного текста.
- **Guardrails**: budget/cooldown/anti-trivial + reason/stakes required.

### P1 — качество/погружение/стабильность
- **Починка `/battlefield`**: прозрачность боя и дебаг.
- **Стабильность JSON**: меньше repair/fallback, валидные поля для боя.
- **Инженерные алерты**: фикс пустого `{}` analyzer, JSON валидация, RAG индексация, токены GigaChat.

### P2 — рост и удержание (после P0/P1)
- **Ежедневки/стрик**: мягкие награды/цели для retention.
- **Мини‑ивенты**: короткие сценки без обязательных чеков.

### P3 — социальность/вирусность (позже)
- **Партия/мультиплеер**: очередь решений, совместный бой.
- **Лидерборды**: когда стабильные метрики.
- **Гильдии**: при устойчивом retention.

### P4 — "вау" визуализация
- **Изображения**: локации/NPC/предметы + текстовый fallback.
- **Улучшенная карта**: связи, выделение текущей локации.

## Новые продуктовые идеи (генерация 2026)

### Идеи для улучшения погружения (P1)
- **Персонализация мира**: адаптация описаний под стиль игрока (темный/светлый, детальный/лаконичный).
- **Вариативность событий**: 3-5 вариантов развития на ключевых точках вместо линейности.
- **Аудио-описания**: эксперимент с голосовым ботом для атмосферных сцен (без боя).

### Идеи для баланса механик (P0-P1)
- **Сложность адаптивная**: DC корректируется по успехам/провалам игрока в сессии.
- **Cooldown на проверки**: нельзя спамить одинаковыми навыками подряд.
- **Anti-trivial guardrail**: запрет проверок на очевидные вещи ("осмотреть комнату без деталей").

### Идеи для вовлеченности (P2)
- **Достижения**: коллекция badge за редкие события (первая победа в бою, исследование всех локаций).
- **Прогресс персонажа**: визуализация роста (уровень, навыки, инвентарь) без спойлеров.
- **Сессионные цели**: "дойти до конца данжа" с таймером и наградами.

### Идеи для социальности (P3)
- **Совместные приключения**: 2-3 игрока в партии с разделением ролей.
- **Шеринг историй**: экспорт лучших моментов для соцсетей.
- **Глобальные события**: редкие кросс-сессионные ивенты для всех игроков.

### Идеи для монетизации (P4, если retention стабилен)
- **Премиум персонажи**: уникальные классы/расы с эксклюзивными историями.
- **Расширения мира**: новые данжи/кампании за символическую плату.
- **Донат на развитие**: поддержка команды для новых фич (изображения, голос).
