- Guardrails: budget/cooldown/anti-trivial + reason/stakes
- Text-only UX: `/roll` резолвит pending проверки
- Location events lifecycle (0..N событий, статусы)
- Стабильность JSON: улучшенная валидация и repair логика
- GigaChat rate limiting оптимизация (429 errors)
- Image generation timeouts и fallback логика
- RAG индексация stability (фикс "провалов памяти")
- DM Analyzer валидация и fallback для битых полей

### ❌ Главная проблема
- **Утечка внутренней кухни**: ловушки/проверки просачиваются в DM текст
- **Преждевременные предупреждения**: игрок знает о ловушках до активации
- **Блокировка после провала**: после провала проверки система блокирует дальнейшие действия
- Промпт-инструкции не работают: DM спамит проверками

## Backlog по приоритетам

### P0 — "должно просто работать"
- **Фикс утечки ловушек**: analyzer не должен предупреждать о ловушках заранее
- **Автопродолжение после провала**: после провала проверки DM автоматически продолжает повествование
- Ловушки активируются только при действиях игрока → тогда проверка навыка

### P1 — стабильность и качество
- **Фикс утечки внутренней кухни**: ловушки не должны просачиваться в DM текст
- **Оптимизация генерации изображений**: DM использует слишком часто, нужны rate limits
- RAG индексация stability (фикс "провалов памяти")
- GigaChat token expiry fix
- Image download fallback (403 errors)

### P2 — вовлеченность и retention
- Достижения/achievements system
- Ежедневные квесты и стрики
- Прогресс персонажа (визуализация роста)

### P3 — социальность
- Совместные приключения (2-3 игрока)
- Шеринг лучших моментов
- Глобальные события

### P4 — монетизация и "вау"
- Генерация изображений (локации/NPC)
- Аудио-описания для атмосферы
- Премиум контент (классы/кампании)

## Новые идеи 2026

### Игровая механика
- **Адаптивная сложность**: DC корректируется по успехам игрока в сессии
- **Вариативность событий**: 3-5 веток развития вместо линейности
- **Cooldown система**: защита от спама одинаковыми проверками

### Погружение
- **Персонализация мира**: темный/светлый стиль описаний
- **Мини-ивенты**: короткие сценки без обязательных чеков
- **Сессионные цели**: "дойти до конца данжа" с таймером

### Социальность
- **NPC компаньоны**: NPC могут присоединяться к отряду игрока
- **Партии**: очередь решений, совместный бой
- **Лидерборды**: по редким достижениям
- **Гильдии**: групповые активности

### Технические улучшения
- **Улучшенная карта**: связи локаций, текущая позиция
- **Rate limiting**: защита от спама запросов
- **Валидация JSON**: pre/post processing для стабильности
