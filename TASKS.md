## 🚨 Активные задачи

### P0 — Критические ошибки (исправить немедленно)

- **Утечка информации о ловушках в DM текст ✅**
  - Симптом: Текст типа "Ловушка в замке древних теней..." появляется в ответах DM
  - Влияние: Игрок знает о ловушках заранее, ломает погружение
  - Action items:
    - Исправить analyzer-first логику: ловушки не должны предупреждать заранее
    - Ловушки активируются только при действиях игрока → тогда проверка навыка
    - Добавить guardrail: запрет просачивания внутренних триггеров в narrative
  - Как проверить: DM не предупреждает о ловушках, только активирует их при взаимодействии
  - ✅ Выполнено: убрана утечка описания ловушек из контекста DM, добавлен guardrail в промпт

- **Автопродолжение после провала проверки ✅**
  - Симптом: После провала проверки система блокирует игру, требует "другой подход"
  - Влияние: Прерывает течение игры, игрок не знает что делать дальше
  - Action items:
    - После провала проверки DM автоматически продолжает повествование с последствиями
    - Убрать блокировку повторных проверок одного типа
    - Добавить естественное развитие сюжета после провалов
  - Как проверить: После провала проверки DM сразу описывает последствия и продолжает историю
  - ✅ Выполнено: DM теперь получает результат проверки в контексте и автоматически продолжает повествование после провалов

- **Автопродолжение после успешной проверки ❌**
  - Симптом: Даже после успешной проверки (17) система пишет "проверка уже выполнена"
  - Влияние: Успешные проверки тоже блокируют игру, DM не продолжает повествование
  - Action items:
    - После успешной проверки DM должен автоматически продолжить с положительными последствиями
    - Исправить логику resolve pending check для success случаев
    - Убедиться что DM получает результат успеха в контексте
  - Как проверить: После успешной проверки DM сразу описывает успех и продолжает историю

- **Оптимизация частоты генерации изображений DM ✅**
  - Симптом: DM слишком часто использует генерацию изображений
  - Action items:
    - Добавить rate limiting для изображений (макс N изображений за сессию/час)
    - Приоритизировать изображения для ключевых моментов (боссы, важные локации)
    - Добавить текстовый fallback для частых генераций
    - Настроить DM prompt: "Используй изображения sparingly для важных сцен"
  - Как проверить: DM использует изображения только для ключевых моментов
  - ✅ Выполнено: добавлен rate limiting (макс 3 изображения за сессию), обновлен промпт DM с инструкцией использовать изображения sparingly
